# Headrace

OTel-native, stateful stream processing in a single Rust binary. Run stateful, event-time
aggregations over OpenTelemetry and forward the aggregated metrics to your backend, not every
datapoint.

Run it in-process for dev and the edge, or scale it across a cluster over a partitioned
backend. Same pipeline, either way.
