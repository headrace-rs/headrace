# Headrace

OTel-native, stateful stream processing in a single Rust binary. Point OTLP at it,
pre-aggregate telemetry, and ship windowed rollups downstream instead of the raw firehose.

Run it in-process for dev and the edge, or scale it across a cluster over a partitioned
backend. Same pipeline, either way.
